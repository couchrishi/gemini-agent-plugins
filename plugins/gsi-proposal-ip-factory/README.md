# GSI Proposal Architecture, SOW Margin & Bench Factory (`gsi-proposal-ip-factory`)

Models consulting delivery staffing pyramids and onshore/offshore margin leverage, audits SOW drafts for scope creep phrasing and margin breaches, and matches open project roles to bench consultants.

## Included Workflow Skills

1. **`winning-proposal-architect`** ([SKILL.md](skills/winning-proposal-architect/SKILL.md)) — Calculates multi-phase effort hours, onshore/offshore leverage ratio, blended bill rate, and gross margin vs SOW floor.
2. **`sow-scope-margin-auditor`** ([SKILL.md](skills/sow-scope-margin-auditor/SKILL.md)) — Lints SOW drafts for unbounded 'all work required' obligations, missing acceptance criteria, >10d deemed acceptance, and margin floors.
3. **`bench-skill-demand-matcher`** ([SKILL.md](skills/bench-skill-demand-matcher/SKILL.md)) — Matches open project seats against bench skills, roll-off dates, location overlap, and target role margin.

- **Granular 1-Hop Upload:** `dist/skills/winning-proposal-architect.zip`, `dist/skills/sow-scope-margin-auditor.zip`, `dist/skills/bench-skill-demand-matcher.zip`
