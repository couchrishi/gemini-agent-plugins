Upload a Skill Archive and Run in Gemini Enterprise (/work)

Skills run natively on live /work 1P connectors (remote_cli mcp) and customer BYO-MCP servers, and support optional zero-connector .xlsx / .docx sandbox files from examples/ for 2-minute offline workshops.

  1. Open the Catalog view, filter by your persona, and download either dist/bundles/<plugin-id>.zip (all 3 skills + shared trap guides) or a focused single-hop dist/skills/<skill-id>.zip.
  2. Open Gemini Enterprise web app (/work) → left navigation Skills → + → Upload skill → select .zip → Import (Standard, Plus, or Pay-as-you-go edition).
  3. Prompt naturally in chat or invoke /<skill-id> or @<skill-id> against your authorized enterprise connectors, or attach the matching starter workbook/doc from examples/<plugin-id>/ when testing offline.
  4. For custom customer exports or non-standard columns, inspect headers and tabs directly in pyrepl via scripts/enterprise_io.py, shape fields in Python into a canonical payload dict (calling ask_question only if ambiguous), call analyze(payload, config=...), and confirm any Auto-Guardian write prompt before execution.

Bind Tenant Thresholds Without Editing Source Code

Default packages ship with org_configured: false and stamp reports with [EVALUATED AGAINST STANDARD BASELINE — BIND ORG CONFIG TO CUSTOMIZE]. Binding an organization config validates materiality caps, SLA targets, and covenant overrides against .gemini-plugin/config.schema.json.

  1. Create an organization JSON file overriding global defaults or plugin-specific numeric/policy thresholds.
  2. Run tools/package.py --org-config to validate every override and stamp tenant-ready .zip archives into an isolated output directory.
  3. Import the stamped archives via /work → Skills → + → Upload skill; org_configured: true automatically suppresses the standard baseline banner.
  4. Inspect each plugin's Schema & Governance tab to review required canonical fields, Auto-Guardian write confirmations, Python invariants, and schedule_task crons.

Validate Schemas, Compile Explorer Data, and Run Full-Scale Benchmarks

All 60 Python engines and the benchmark corpus generator run on Python 3.11+ standard library with zero third-party runtime dependencies inside skill archives.

  1. make validate validates plugin.json and config.schema.json Draft 2020-12 schemas, 5-field crons, 140 SKILL.md manifests, SHA-256 checksums, relative links, and clean-room hygiene.
  2. make check ensures zero drift across materialized references/, dist/ zips, and docs/catalog_data.js.
  3. make test runs the full pytest suite covering all 60 deterministic engines, enterprise_io.py readers/schema checks, and packaging validation.
  4. make benchmark regenerates the full 60,089-row suite (12 .xlsx, 3 .docx, 5 .pdf) in under 15 seconds and exercises every engine locally.
